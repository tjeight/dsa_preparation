# DSA Preparation Roadmap

A progressive path to master Data Structures and Algorithms in Python.

---

## Phase 1: Foundations
1. **Time & Space Complexity**
   - Big-O, Big-Omega, Big-Theta notation
   - Best, average, worst case analysis
2. **Built-in Python Structures & Mechanics**
   - Lists, tuples, sets, dictionaries
   - Memory models, amortized complexity
3. **Mathematics & Bit Manipulation**
   - Prime factorization, GCD (Euclidean algorithm), sieve of Eratosthenes
   - Bitwise AND, OR, XOR, shifts, masking

---

## Phase 2: Linear Data Structures
1. **Arrays & Strings**
   - Two Pointers
   - Sliding Window (fixed and dynamic size)
   - Prefix Sum & Difference Arrays
2. **Linked Lists**
   - Singly, Doubly, and Circular Linked Lists
   - Fast & Slow pointers (Tortoise & Hare, cycle detection)
   - In-place reversal
3. **Stacks & Queues**
   - LIFO / FIFO mechanics
   - Monotonic Stack & Monotonic Queue
   - Implementation using `collections.deque`

---

## Phase 3: Non-Linear Data Structures
1. **Hashing**
   - Hash maps & hash sets
   - Collision handling (chaining vs open addressing)
2. **Trees**
   - Binary Trees, Binary Search Trees (BST)
   - Tree Traversals: In-order, Pre-order, Post-order, Level-order (BFS)
   - Lowest Common Ancestor (LCA)
   - Self-balancing trees overview (AVL, Red-Black)
3. **Heaps & Priority Queues**
   - Min-heap & Max-heap (`heapq` module)
   - Top-K elements, Two Heaps pattern

---

## Phase 4: Core Algorithmic Techniques
1. **Searching & Sorting**
   - Binary Search (on arrays and on answer spaces)
   - Quick Sort, Merge Sort, Counting Sort, Quickselect
2. **Recursion & Backtracking**
   - Subsets, Permutations, Combinations
   - Pruning and constraint satisfaction (N-Queens, Sudoku)
3. **Greedy Algorithms**
   - Interval scheduling, greedy choice property

---

## Phase 5: Advanced Structures & Graph Theory
1. **Graphs**
   - Representations: Adjacency list, Adjacency matrix
   - Breadth-First Search (BFS) & Depth-First Search (DFS)
   - Topological Sort (Kahn's algorithm, DFS)
   - Shortest paths: Dijkstra, Bellman-Ford, Floyd-Warshall
   - Minimum Spanning Tree: Kruskal (DSU) & Prim
2. **Disjoint Set Union (DSU / Union-Find)**
   - Path compression and union by rank
3. **Tries (Prefix Trees)**
   - Prefix matching, autocomplete, bitwise trie
4. **Segment Trees & Fenwick Trees (Binary Indexed Tree)**
   - Range queries and point/range updates

---

## Phase 6: Dynamic Programming
1. **1D DP**
   - Fibonacci, Climbing Stairs, House Robber
2. **2D & Grid DP**
   - Unique Paths, Minimum Path Sum
3. **Classical DP Archetypes**
   - 0/1 Knapsack & Unbounded Knapsack
   - Longest Common Subsequence (LCS)
   - Longest Increasing Subsequence (LIS)
   - Matrix Chain Multiplication / Interval DP
   - DP with Bitmasking
